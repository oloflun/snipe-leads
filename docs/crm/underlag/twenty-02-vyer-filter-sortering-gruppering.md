## Översikt

En **vy** (view) är ett sparat sätt att titta på poster av ett objekt (t.ex.
Företag, Personer, Affärer). Varje objekt har minst en vy, och vyn bär allt
som styr hur listan ser ut: vilken **vytyp** (tabell, tavla, kalender, karta
m.fl.), vilka **vyfält** (kolumner/kortfält) som syns och i vilken ordning och
bredd, vilka **vyfilter** och **filtergrupper** som avgränsar posterna, vilka
**vysorteringar** som ordnar dem, och, för tavla och grupperad tabell, vilket
fält som **grupperar** posterna och vilka **vygrupper** (ett per värde) som
syns och i vilken ordning. Vyn kan ha **aggregat** (summeringar) per kolumn i
tabellens sidfot och per kolumn på tavlan.

Ändringar som användaren gör i en vy (ett nytt filter, en ny sortering) hålls
först som **osparade ändringar** ovanpå den sparade vyn; användaren väljer att
spara dem i vyn, spara som ny vy eller förkasta dem.

Servern lagrar vyn och dess delar som metadata (en tabell per del: view,
viewField, viewFieldGroup, viewFilter, viewFilterGroup, viewGroup, viewSort);
filtren översätts av servern och av fronten till en sökfråga mot posterna.

### Begrepp och förslag på svensk term

| Förlagans begrepp | Svensk term | Kort |
|---|---|---|
| View | Vy | Sparad lista över ett objekts poster |
| View type: TABLE / KANBAN / CALENDAR / (MAP) | Tabell / Tavla / Kalender / Karta | Hur posterna ritas |
| View field | Vyfält (kolumn) | Fält som visas i vyn, med position, bredd, synlighet |
| View field group | Fältgrupp | Namngiven grupp av vyfält (sektion) |
| View filter | Vyfilter | Ett villkor: fält + operand + värde |
| View filter group | Filtergrupp | OCH/ELLER-gruppering av filter, kan nästlas |
| Advanced filter | Avancerat filter | Filtergrupper som användaren bygger själv |
| View sort | Sortering | Fält + riktning (stigande/fallande) |
| View group / record group | Grupp (kolumn på tavlan, sektion i tabellen) | Ett värde i grupperingsfältet |
| Aggregate operation | Summering | Antal, summa, medel, min, max, procent tomma m.m. |
| Kanban field | Grupperingsfält | Valfält som tavlans steg bygger på |
| Calendar field | Kalenderfält | Datumfält kalendern placerar posterna efter |

| Key (INDEX) | Huvudvy | Objektets standardvy som inte kan raderas |
