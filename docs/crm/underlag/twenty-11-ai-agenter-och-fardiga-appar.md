# Twenty som förlaga: AI, agenter och färdiga appar

Underlag för Snajp CRM. Funktionsbeskrivning med egna ord, skriven ur Twentys källkod
(grund klon `D:\snajp-crm-forlaga\twenty`, commit 1da6d55, 2026-11-24). Ingen kod,
inga typdefinitioner och inga frågedokument är kopierade. Sökvägar är relativa till
klonens rot. ID-prefix: AI.

## Översikt

AI-delen i förlagan har fem lager som bygger på varandra:

1. **Modellkatalog och leverantörer** (avsnitt D). Instansen har en katalog över
   språk-, transkriptions- och utvärderingsmodeller från flera leverantörer.
   Arbetsytan väljer inte modell direkt utan en **nivå** (extra snabb, snabb,
   balanserad, smart, extra smart) som Twenty fyller med bästa tillåtna modell,
   filtrerad genom arbetsytans **datapolicy** (region, nolllagring).
2. **Verktyg och färdigheter** (E, F). Ett **verktyg** (tool) utför något:
   postoperationer per objekt, åtgärder (HTTP, e-post, kalender, kodtolk, filer),
   arbetsflöden, appars funktioner och verktyg från anslutna externa
   **MCP-servrar**. En **färdighet** (skill) är en namngiven instruktionstext som
   lär assistenten hur något görs; den laddas vid behov. Allt styrs av roller och
   behörighetsflaggor, och skrivande verktyg kan kräva **godkännande**.
3. **Agenter och körningar** (B, avsnitt AI-050–074). En **agent** är en sparad
   konfiguration: instruktion, modell, roll, svarsformat och **utlösare**
   (posthändelse eller schema). En **körning** (tur) loggas med tokens, krediter
   och verktyg. Agenter kan pausa för att fråga en människa, föreslå en åtgärd
   för godkännande eller vänta på en händelse.
4. **Chatten och inkorgen** (C, I). Assistenten (standardnamn Ada) är en agent
   man pratar med i sidopanelen. Chatten har vuxit till en **inkorg för
   konversationer** mellan medlemmar, assistent och agenter, med trådar,
   direktmeddelanden, kanaler styrda av roller, tilldelning, snooze och notiser.
   Sidans **kontext** (post, listvy, inställningssida) skickas med.
5. **Appar** (K–M). Färdiga appar lägger till objekt, fält, agenter,
   logikfunktioner och widgetar för mötesinspelning, meddelandekanaler,
   berikning och webbsökning. **Slack** är den enda appen som låter användaren
   prata med agenten via en extern kanal.

Runt detta finns **krediter och mätning** (G): all förbrukning räknas om till
krediter (1 kredit = 0,000001 dollar), med personlig veckokvot per medlem och
arbetsytans krediter som reserv. Mätning och kvotprövning är Enterprise-märkta.

Förslag på svenska termer: agent = agent; körning/turn = körning (tur);
skill = färdighet; tool = verktyg; thread = konversation (tråd); channel = kanal
(delad inkorgsmapp); inbox = inkorg; snooze = skjut upp; mention = omnämnande;
assignee = tilldelad; approval / proposed tool call = godkännande / föreslagen
åtgärd; model tier = modellnivå (läge); data policy = datapolicy; data residency
= dataplacering; zero data retention = nolllagring; credits = krediter;
user credits = personlig AI-kvot; browsing context = sidkontext; front component
= frontkomponent (widget); logic function = logikfunktion; connection provider
= anslutningsleverantör; call recording = samtalsinspelning.

Obs. om uppdraget: "agentkanaler (chatt via externa kanaler)" motsvaras i
förlagan inte av metadata-modulen agent-chat-channel (som är interna
inkorgskanaler, AI-107–109) utan av apparna Slack (AI-316), samt WhatsApp och
LinkedIn som meddelandekanaler utan agent (AI-314, AI-318).
